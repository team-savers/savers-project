# 세이버스(SAVERS) 실행 타임라인 — 2단계 골 구조

`docs/역할_가이드/`의 역할별 작업을 **시간축에 배치**한 문서 모음입니다. 매뉴얼이 "누가 무엇을 하는가"라면, 이 폴더는 "언제, 무엇을 끝내야 다음이 풀리는가"를 다룹니다. 역할 번호 체계는 [역할_가이드/](../역할_가이드/)와 동일합니다.

## 2단계 골(Goal) — 이 프로젝트가 통과해야 할 두 관문

전체 일정은 **순차적인 두 개의 골**로 재설정되었습니다. 각 골은 "무엇이 되면 통과인가"를 못박는 **Exit Criteria(통과 조건)** 를 가지며, 앞 골을 통과하지 못하면 뒤 골은 시작되지 않습니다.

| 골 | 기간 | 목표 한 줄 | 통과 판정 |
|---|---|---|---|
| **Stage 1 · 예선 통과** | 7/27 ~ 8/10 13:00 | 실데이터 수직 관통 + **부분 실측 지표**로 재현 가능한 제출본 완성 | 아래 [Stage 1 Exit Criteria](00-overall.md#stage-1-exit-criteria--예선-통과-판정) 전항 충족 + 8/10 제출 |
| **Stage 2 · 본선 발표** | 8/11 ~ 9월 초 | **킬러 데모** 완결 + 4대 지표 정식 실측값 교체 + 발표 | 아래 [Stage 2 Exit Criteria](00-overall.md#stage-2-exit-criteria--본선-발표-판정) 전항 충족 + 본선 시연 |

> **Stage 1 완성도 기준선 = "중간(관통 + 부분 실측)"** (팀 확정). 8/10까지 실데이터 수직 관통을 **달성 목표**로 하되, 4대 지표 중 **근거 일치율·알림 도달 속도는 실측값**을 확보하고 **환각 억제율·메시지 명확성은 1차 측정치(잠정)** 로 제출합니다. 이는 v4 기획서 「진행 현황·예선 제출 시점」 서술과 정합하며, 잔여 실측·평가셋 확장은 Stage 2에서 정식 교체합니다.
