# 세이버스(SAVERS) 비용 산정

[외부_승인.md](외부_승인.md)에서 식별한 승인·계정 항목에는 "승인이 필요한가"만 있고 **"얼마가 드는가"**가 빠져 있습니다. 이 문서는 그 항목들에 비용 축을 붙여, 예선(2026-07-27~08-10)과 본선(~09-03) 기간에 실제로 지출될 금액을 산정합니다.

> **이 문서의 수치는 계획값입니다.** 공개 요금표가 없거나 시점·계약에 따라 달라지는 단가는 **가정 단가**로 계산하고 신뢰도를 표기했습니다. 실제 신청·결제 시점에 확인한 값으로 단가 셀만 교체하면 총액이 갱신되도록 계산식을 함께 적었습니다. 확인 담당·시점은 9절 체크리스트에 있습니다.

## 3. 외부_승인.md 항목별 상세

### A. 공공데이터/Open API — **0원**

기상청·소방청·행정안전부 재난안전데이터 공유 플랫폼, 공공데이터포털 행정동 코드표, 국민행동요령 원문 모두 **활용신청은 무료**입니다(확실한 사실). 비용이 아니라 **리드타임과 호출 한도**가 제약입니다.

- 승인 대기(수일)로 일정이 밀리는 것이 실질 비용 → [리스크.md](리스크.md) ④, 일정 지연 리스크로 관리
- 호출 한도 초과 시 유료 전환이 아니라 **차단**되는 경우가 많음 → 스케줄러 폴링 주기를 한도에 맞춰 설계해야 함(예: 일 1,000회 한도면 폴링 60초 주기로도 하루 1,440회 초과)
- 국가승인통계·공공저작물 인용은 출처 표기 의무만 있고 이용료 없음

|---|---:|---:|---:|
| **알리고** (예선 채택안) | 7.5원 | 8.4원 | **약 8,000원** |

### D. AI/클라우드 — **약 305,000원 (전체의 80%)**

비용의 대부분이 여기 집중됩니다.

#### D-1. AWS 단일 VM (서울 리전) — 약 170,000원

[ADR-0003](../adr/0003-single-vm-seoul.md)에 따라 GPU 없이 CPU 단일 VM + docker-compose로 운영합니다. 인스턴스 사이징은 **메모리가 결정**합니다.

| 구성 요소 | t3.medium (2vCPU/4GB) | t3.large (2vCPU/8GB) |
|---|---:|---:|
| 인스턴스(온디맨드, 730h) | 약 53,000원/월 | 약 106,000원/월 |
| EBS gp3 30GB | 약 4,000원/월 | 약 4,000원/월 |
| 퍼블릭 IPv4 (탄력적 IP) | 약 5,000원/월 | 약 5,000원/월 |
| 데이터 전송(아웃바운드) | 월 100GB 무료 한도 내 → 0원 | 0원 |
| **월 합계** | **약 62,000원** | **약 115,000원** |
| **5.5주(1.5개월) 합계** | **약 93,000원** | **약 172,000원** |

신뢰도: 추정 (AWS 요금은 시점·리전별 변동. 콘솔 요금 계산기로 재확인 필요)

**사이징 판단 (엣지/메모리 예산 관점)** — backend + ai-engine + Chroma 3개 컨테이너가 상시 2~3GB를 점유합니다. 여기서 갈립니다.

- **임베딩을 외부 API로** 처리하면 4GB(t3.medium)로 충분 → 월 5만원 절감, 대신 D-2의 임베딩 API 비용 발생
- **임베딩을 로컬 모델(BGE-M3 등)로** 처리하면 모델 상주에 2.5GB 내외가 추가로 필요 → 4GB에서는 인덱싱 중 OOM 위험이 실재하므로 **t3.large 필요**. API 비용은 0원이 되지만 VM 비용이 월 5만원 늘고, CPU 임베딩이라 인덱싱 시간도 길어집니다.
- **결론**: 임베딩 비용(D-2)이 1만원 수준이므로 **API 임베딩 + t3.medium 조합이 총비용에서 유리**합니다. 로컬 임베딩은 비용이 아니라 "외부 API 장애 시 재인덱싱 가능"이라는 가용성 근거로만 선택하십시오. 기본 시나리오는 안전 마진을 두어 t3.large로 잡았습니다.

#### D-2. HyperCLOVA X 생성 API — 약 100,000원 (변동성 최대)

⚠️ **NCP CLOVA Studio 요금은 모델·시점별로 달라 콘솔 실확인이 필수입니다(불확실).** 아래는 **가정 단가**를 넣은 계산식이며, 실단가 확인 후 단가 셀만 교체하십시오.

```
호출 수 4,000회 × (입력 2,500토큰 + 출력 350토큰)
  = 입력 10.0M 토큰 / 출력 1.4M 토큰

입력: 10,000 × (가정 5원/1K토큰)  =  50,000원
출력:  1,400 × (가정 15원/1K토큰) =  21,000원
                             소계 =  71,000원
  + 재시도·디버깅 여유 40%       ≈ 100,000원
```

호출 수 4,000회의 내역: 개발·디버깅 2,000 / 평가 리런 1,200(=50건 × 가드레일 on·off × 12회) / E2E·리플레이 500 / 데모 리허설 300.

**단가가 가정의 2배로 나와도 20만원**이므로 프로젝트를 흔들지는 않지만, **리런 횟수가 지수적으로 늘면 위험**합니다(8절 참고).

#### D-3. 임베딩 — 약 10,000원 또는 0원

```
코퍼스 청크 2,000개 × 500토큰 = 1.0M 토큰
재인덱싱 10회                 = 10.0M 토큰
쿼리 임베딩 4,000회 × 100토큰 =  0.4M 토큰
합계 10.4M 토큰 × (가정 0.5원/1K) ≈ 5,200원 → 여유 포함 10,000원
```

로컬 모델(BGE-M3 등) 선택 시 0원이나, D-1의 VM 사이징 트레이드오프가 붙습니다.

### 4-1. 교차 채점 LLM — 약 40,000원

[리스크.md](리스크.md) ⑦이 "교차 채점 모델의 구체 모델·비용·API 한도 계획이 비어 있다"고 지적한 항목입니다. 생성 모델(HyperCLOVA X)과 **다른 모델**이어야 자기평가 편향을 피할 수 있으므로, 외부 모델 계정이 추가로 필요합니다.

```
채점 호출 4,000회 (50건 × 4지표 × on/off × 리런 10회)
  × (입력 1,800토큰 + 출력 300토큰)
  = 입력 7.2M 토큰 / 출력 1.2M 토큰
```

| 후보 모델 | 단가(입력/출력, 100만 토큰당) | 산정액 | 판단 |
|---|---|---:|---|
| Claude Haiku 4.5 | $1 / $5 | $13.2 ≈ 18,000원 | 최저가지만 아래 캐싱 이슈 있음 |
| **Claude Sonnet 5** | **$3 / $15** (2026-08-31까지 도입가 **$2 / $10**) | **$26.4 ≈ 37,000원** (도입가 적용 시) | **권장** |

신뢰도: 확실한 사실(Anthropic 공식 요금표 기준). 단, **도입가 적용 기한 2026-08-31은 예선 전 기간과 본선 준비 대부분을 덮습니다** — 이 기간에 채점을 끝내면 사실상 $2/$10로 계산됩니다.

**Sonnet 5를 권장하는 실질 근거는 프롬프트 캐싱입니다(높은 신뢰).** 채점은 동일한 채점 기준 프롬프트를 수천 번 재전송하는 작업이라 캐싱 효과가 큰데, 캐시가 걸리는 최소 프리픽스 길이가 모델마다 다릅니다 — Sonnet 5는 1,024토큰, Haiku 4.5는 4,096토큰입니다. 채점 기준 프롬프트가 1,500~2,000토큰 규모라면 **Haiku에서는 캐시가 아예 걸리지 않고(에러 없이 조용히 미적용) Sonnet 5에서만 걸립니다.** 캐시 읽기는 입력 단가의 약 0.1배이므로, 캐싱이 적용되면 Sonnet 5의 입력 비용이 대폭 줄어 명목 단가가 3배인데도 실집행액이 역전될 수 있습니다.

⚠️ 결제에 **해외 결제 가능 카드**가 필요합니다. NCP·AWS와 결제 수단이 다를 수 있으니 7절과 함께 확인하십시오.

### 4-2. 도메인 + HTTPS — 약 20,000원/년

**PWA는 HTTPS가 필수**이고 브라우저 Geolocation API도 보안 컨텍스트(HTTPS)에서만 동작하므로, 도메인 없이는 위치 확인 흐름 자체가 데모되지 않습니다.

| 항목 | 금액 |
|---|---:|
| 도메인 등록(.com 등, 1년) | 약 15,000~20,000원 |
| TLS 인증서 (Let's Encrypt) | 0원 |
| Route 53 호스팅 영역 (사용 시) | 약 700원/월 |

## 5. 항목별 변동비 산정식 (실측 후 재계산용)

실단가를 확인하면 아래 식의 단가만 바꿔 총액을 갱신하십시오. 이 식들은 `apps/ai-engine/eval/` 하네스가 실제 호출 수를 로깅하면 실측값으로 대체됩니다.

```
LLM 생성 비용   = 호출수 × (입력토큰 × 입력단가 + 출력토큰 × 출력단가)
교차 채점 비용  = 평가셋크기 × 지표수 × 2(가드레일 on/off) × 리런횟수 × 회당토큰 × 단가
알림 발송 비용  = (알림톡 건수 × 알림톡단가) + (폴백 SMS 건수 × SMS단가)
번역 비용       = 언어수 × 메시지길이(자) × 건수 × 글자당단가
인프라 비용     = (인스턴스시간당 + 스토리지 + 고정IP) × 운영시간
```

**리런 횟수가 곱셈 항에 두 번 들어간다**는 점에 유의하십시오. 평가셋을 30건에서 50건으로 늘리면서 리런을 10회에서 20회로 올리면 채점 비용은 3.3배가 됩니다.
