# 세이버스(SAVERS) 외부 승인 체크리스트

프로젝트 개발을 위해 외부 기관·플랫폼의 승인, 신청, 계정 개설이 필요한 요소를 정리한 문서입니다. 리드타임이 긴 항목부터 예선 초반에 확인해야 합니다.

## A. 공공데이터/Open API 승인

- [ ] **기상청 Open API** (공공데이터포털 또는 기상청 API허브) — 활용신청 → 심사 → 승인까지 통상 수일 소요. 신청 시 활용 목적(호우특보 실시간 연동)을 명확히 기재해야 승인이 지연되지 않음.
- [ ] **소방청 재난안전데이터 공유 플랫폼 Open API** — 별도 계정·활용신청 필요. 트래픽 제한(호출 한도) 확인 필수.
- [ ] **행정안전부 재난안전데이터 공유 플랫폼 Open API** — 위와 동일한 신청 절차, 승인 기관이 달라 별도로 진행해야 함.
- [ ] **행정안전부 국민행동요령 원문 활용 허가 확인** — 공공저작물 자유이용허락 표시(제1유형~4유형 등) 여부를 소스별로 확인. 출처 표기 의무 여부도 함께 체크.
- [ ] **행정안전부 「2025년 재난·사고 피해조사」 통계 인용 허가 확인** — 신청서·기획서에 이미 인용 중이므로, 국가승인통계 인용 시 출처 표기 규정 준수 여부 재확인.

## B. 위치/지도 API 승인

- [ ] **카카오맵 API (역지오코딩·길찾기)** — 카카오 디벨로퍼스 앱 등록 + API 키 발급. 무료 호출 한도를 초과하면 유료 전환 필요, 사업자 등록 여부에 따라 한도가 달라질 수 있음.
- [ ] **행정동 코드 매핑 데이터** — 공공데이터포털 법정동/행정동 코드표 다운로드는 대부분 즉시 가능하나, 최신본 갱신 주기 확인.

## C. 메시징/알림 채널 승인

> **[ADR-0005](../adr/0005-webpush-primary-channel.md)로 이 절의 성격이 바뀌었습니다.** 1차 채널이 웹푸시(FCM)로 전환되면서
> 카카오 알림톡 4개 항목(채널 개설·비즈니스 인증·발신 프로필 심사·템플릿 사전 승인)이 **없어졌고**,
> 그와 함께 **이 절은 더 이상 최장 리드타임 항목이 아닙니다**. 웹푸시에는 발신 전 외부 심사가 없습니다.
> **알림톡은 예선·본선 모두 채택하지 않습니다**(ADR-0005 "정정 후 입장", 2026-07-30).
> 일차 사유는 생성 문안을 템플릿 슬롯에 반납해야 하는 설계 충돌이고,
> 이차 사유는 발신 프로필이 요구하는 사업자등록 기반 비즈니스 인증 자격입니다.
> 따라서 본선 재도입을 전제한 승인 항목은 이 문서에 두지 않습니다.

- [ ] **웹푸시(1차 채널) 발신 설정** — Firebase Cloud Messaging 프로젝트 생성,
  웹앱 등록, VAPID 키 발급. 백엔드는 Admin SDK 자격증명으로 발송합니다.
  ⚠️ 프로젝트가 **팀 계정 소유**여야 합니다.
  개인 계정에 남아 있으면 팀이 끌 수도 옮길 수도 없는 발송 경로가 생깁니다.
  프로젝트 ID·키 값은 이 저장소가 public이므로 여기 적지 않고 팀 보관소에 둡니다.
- [ ] **HTTPS 배포처 확보** — 웹푸시는 localhost 외에서 HTTPS가 필수라,
  배포처가 없으면 실기기 검증이 불가능합니다.
  프론트는 정적 호스팅으로 나가고([ADR-0008](../adr/0008-frontend-static-hosting.md)),
  백엔드는 단일 VM에 남습니다([ADR-0003](../adr/0003-single-vm-seoul.md)).
  ⚠️ 프론트만 HTTPS에 올라가면 `http://` 백엔드 호출이 혼합 콘텐츠로 막히므로,
  백엔드 TLS 종단과 CORS 허용이 함께 있어야 실기기 검증이 성립합니다.
- [ ] **iOS 웹푸시 제약 확인** — iOS 16.4+ **및** 홈 화면 추가(A2HS) 상태에서만 동작합니다.
  시연 환경은 안드로이드·데스크톱 크롬으로 고정하고,
  A2HS 안내는 대리등록 절차에 포함합니다(당사자 무설치 원칙 유지).

## D. AI/클라우드 플랫폼 계정 및 이용 신청

- [ ] **네이버클라우드플랫폼(NCP) 계정 및 HyperCLOVA X API 이용 신청** — 사용량 기반 과금이므로 팀 예산·결제수단 사전 확보 필요.
- [ ] **AWS 계정 개설 및 결제수단 등록** — 해커톤/스타트업 대상 크레딧 프로그램(AWS Activate 등) 신청 가능 여부 확인.
- [ ] **(선택) 번역 API** — 파파고 API 또는 Google Cloud Translation, 사용량 한도·과금 정책 확인.
- [ ] **(선택) TTS API** — 클로바보이스 등, NCP 계정과 통합 신청 가능한지 확인.

## E. 개인정보/법적 승인·검토

> QA/Security의 실제 점검표(법령·고시 매핑, 검증 방법)는 [개인정보_체크리스트.md](개인정보_체크리스트.md) 참고.

- [ ] **개인정보처리방침 수립 및 동의 절차 설계** — 위치정보(세션 단위), 장애 여부(민감정보) 수집·이용에 대한 별도 동의 문구 필요.
- [ ] **민감정보 처리 관련 내부 검토** — 장애 여부는 개인정보보호법상 민감정보로 분리 동의가 원칙. 지자체·복지관 대리등록 시 위탁 근거 명확화 필요.
- [ ] **(실서비스 확장 시) 지자체·복지관과의 데이터 연계 협의/MOU** — 해커톤 MVP 단계에서는 시뮬레이션 데이터로 대체 가능하나, 실제 복지대상자 DB 연계를 시연에 포함한다면 최소한 협의 의향서 수준의 근거가 필요.
