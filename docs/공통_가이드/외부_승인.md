# 세이버스(SAVERS) 외부 승인 체크리스트

프로젝트 개발을 위해 외부 기관·플랫폼의 승인, 신청, 계정 개설이 필요한 요소를 정리한 문서입니다. 리드타임이 긴 항목부터 예선 초반에 확인해야 합니다.

## A. 공공데이터/Open API 승인

- [ ] **기상청 Open API** (공공데이터포털 또는 기상청 API허브) — 활용신청 → 심사 → 승인까지 통상 수일 소요. 신청 시 활용 목적(호우특보 실시간 연동)을 명확히 기재해야 승인이 지연되지 않음.
- [ ] **소방청 재난안전데이터 공유 플랫폼 Open API** — 별도 계정·활용신청 필요. 트래픽 제한(호출 한도) 확인 필수.
- [ ] **행정안전부 재난안전데이터 공유 플랫폼 Open API** — 위와 동일한 신청 절차, 승인 기관이 달라 별도로 진행해야 함.
- [ ] **행정안전부 국민행동요령 원문 활용 허가 확인** — 공공저작물 자유이용허락 표시(제1유형~4유형 등) 여부를 소스별로 확인. 출처 표기 의무 여부도 함께 체크.
- [ ] **행정안전부 「2025년 재난·사고 피해조사」 통계 인용 허가 확인** — 신청서·기획서에 이미 인용 중이므로, 국가승인통계 인용 시 출처 표기 규정 준수 여부 재확인.

## B. 위치/지도 API 승인

- [ ] **카카오맵 API (역지오코딩·길찾기)** — 카카오 디벨로퍼스 앱 등록 + API 키 발급. 무료 호출 한도를 초과하면 유료 전환 필요, 사업자 등록 여부에 따라 한도가 달라질 수 있음.
- [ ] **행정동 코드 매핑 데이터** — 공공데이터포털 법정동/행정동 코드표 다운로드는 대부분 즉시 가능하나, 최신본 갱신 주기 확인.

## C. 메시징/알림 채널 승인 (가장 리드타임이 긴 항목 — [리스크.md](리스크.md) ① 참고)

- [ ] **카카오톡 채널 개설 및 비즈니스 인증** — 발신 주체 확인(사업자등록증 또는 팀/기관 명의) 필요.
- [ ] **카카오 알림톡 발신 프로필(플러스친구) 심사** — 카카오 또는 알림톡 대행사(NHN Cloud, 채널톡 등)를 통한 심사, 통상 수 영업일 소요.
- [ ] **알림톡 메시지 템플릿 사전 승인** — 변수 슬롯 구조로 템플릿을 등록해야 하며, LLM이 완전 자유생성한 문장은 승인이 거부될 수 있음. **예선 초반에 반드시 실제 정책을 확인해야 하는 최우선 항목.**
- [ ] **웹푸시(대체 채널) 발신 설정** — Firebase Cloud Messaging(FCM) 프로젝트 생성, iOS Safari 웹푸시는 iOS 16.4+ 제약 사항 별도 확인.

## D. AI/클라우드 플랫폼 계정 및 이용 신청

- [ ] **네이버클라우드플랫폼(NCP) 계정 및 HyperCLOVA X API 이용 신청** — 사용량 기반 과금이므로 팀 예산·결제수단 사전 확보 필요.
- [ ] **AWS 계정 개설 및 결제수단 등록** — 해커톤/스타트업 대상 크레딧 프로그램(AWS Activate 등) 신청 가능 여부 확인.
- [ ] **(선택) 번역 API** — 파파고 API 또는 Google Cloud Translation, 사용량 한도·과금 정책 확인.
- [ ] **(선택) TTS API** — 클로바보이스 등, NCP 계정과 통합 신청 가능한지 확인.

- [ ] **개인정보처리방침 수립 및 동의 절차 설계** — 위치정보(세션 단위), 장애 여부(민감정보) 수집·이용에 대한 별도 동의 문구 필요.
- [ ] **민감정보 처리 관련 내부 검토** — 장애 여부는 개인정보보호법상 민감정보로 분리 동의가 원칙. 지자체·복지관 대리등록 시 위탁 근거 명확화 필요.
