# fixtures — 재난 API Replay 픽스처

실 재난 API 응답을 1회 수집하여 동결한 파일. 테스트·시연·평가가 전부
동일 픽스처를 사용한다 (동일 입력 -> 동일 출력).

## 규칙

- 픽스처 파일명: {api_source}_{event_type}_{수집일자}.json
  예: kma_flood_warning_20260801.json
- 수집 후 수정 금지. 갱신이 필요하면 새 파일로 추가하고 사유를 이 문서에 기록한다.
- 테스트 코드는 실 API가 아니라 이 디렉토리만 참조한다.
- 시연(킬러데모)도 동일 픽스처로 구동한다.

## 수집 이력

| 파일 | 출처 | 수집일 | 비고 |
|---|---|---|---|
| (예정) | 기상청 특보 API | - | Phase 0에서 수집 |
